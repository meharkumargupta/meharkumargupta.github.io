# Mehar Kumar Gupta — Personal Website

A responsive personal website built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — website structure and content
- `styles.css` — Royal Blue & Silver visual design and responsive layout
- `script.js` — mobile navigation, reveal animations and automatic copyright year
- `assets/` — your supplied photographs and favicon

## Publish with GitHub Pages
1. Extract `mehar-kumar-gupta-website.zip` on your device.
2. Open your existing GitHub repository and select the **Code** tab.
3. Choose **Add file → Upload files**.
4. Upload the contents of the extracted folder: `index.html`, `styles.css`, `script.js`, `README.md`, and the complete `assets` folder.
5. Make sure `index.html` is directly in the repository's root, alongside `styles.css` and `script.js`. Do not upload only the ZIP, and do not place everything inside an extra nested folder.
6. Scroll down, enter a commit message such as `Publish personal website`, and select **Commit changes**.
7. In repository **Settings → Pages**, confirm the publishing source is the `main` branch and `/ (root)` folder, then save if needed.
8. Wait for the GitHub Pages deployment to finish, then open `https://meharkumargupta.com.np/`.

## Photo replacement
Replace the relevant file in `assets/` while keeping its exact filename:
- `mehar-photo-1.jpg` — homepage portrait
- `mehar-photo-2.jpg` — About section
- `mehar-photo-3.jpg` — future ambition section
- `mehar-photo-4.jpg` — personal gallery

If you rename a photo, update its matching `src` in `index.html`.

## Updating your details
Open `index.html` and edit the relevant text. Keep your designation and factual details accurate. Add new education, achievements or interests only when you want them published.

## Domain and HTTPS
This package does not change your registrar or Cloudflare settings. Keep the GitHub Pages custom domain configured as `meharkumargupta.com.np`. Your DNS should continue pointing to GitHub Pages using the records you previously configured. Once GitHub Pages verifies the domain and enables HTTPS, use **Enforce HTTPS** in Settings → Pages if that option is available.

## Notes

- Email uses a working `mailto:` link.
- Social links open in a new tab with safe external-link attributes.
- Google Fonts are loaded from Google Fonts when visitors have an internet connection.
